# NOTO TI — Exemplos dos vídeos

Arquivos usados nos vídeos do canal **NOTO TI** no YouTube. Cada vídeo tem sua própria pasta, com tudo o que você precisa para reproduzir o que foi mostrado.

## Como usar

```bash
git clone https://github.com/josezipf/exemplos.git
cd exemplos
```

Depois, entre na pasta do vídeo que você está assistindo e siga o `README.md` de lá.
